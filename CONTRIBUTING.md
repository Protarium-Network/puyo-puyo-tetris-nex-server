# Contributing

Bug reports and focused pull requests are welcome. Format files you change with `gofmt`, then run `go vet ./...` and `go test ./...` in each affected Go module. Some preserved source files are not globally gofmt-clean; avoid unrelated formatting-only rewrites.

Do not commit credentials, production addresses, console certificates, packet captures containing personal data, or Nintendo copyrighted assets. This project is an independent preservation and interoperability effort and is not affiliated with Nintendo.
